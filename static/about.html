口径说明

涨幅

30 天 / 7 天 / 今日
今天的总星数减去 30 / 7 / 1 天前的总星数。总星数是我们每天自己记录的：抓取 GitHub Trending 页面时看到的数字，加上每天用 GitHub API 读一次过去 30 天上过榜的所有项目。没有恰好那天的记录时，用前后两次记录线性插值。
带 * 的数字
我们的历史还不够时，借用 GitHub 日榜 / 周榜 / 月榜上的数字。GitHub 统计的是新增星标（不扣除取消的），窗口也和我们不同，所以通常比我们的数字高 5–10%。
带 ≥ 的数字
只记录了不到 30 天：这是自第一次记录以来的涨幅，是下限。至少要有 7 天记录才显示。

状态（每天按固定阈值计算）

新上榜
今天上了任何一个榜（日 / 周 / 月），而我们的记录里（2026-03-25 起）它从未上过榜。
爆发
单日涨 ≥ 1,000 星，且至少是它前一周日均涨幅的 3 倍。
回榜
今天在榜，上次抓取不在榜，以前上过榜。
掉榜
上次抓取在榜，今天不在任何榜。
降温
30 天日均 ≥ 300 星，而最近 7 天的日均不到 30 天日均的一半。
持续走红
最近 7 天日均 ≥ 500 星，最近 7 次抓取里至少 5 次在榜，且今天仍涨 ≥ 250 星。
里程碑
